## About Frontend8

[Frontend8 (qianduan8.com)](http://qianduan8.com/) is a blog site and frontend resource directory focused mainly on web frontend development technology content. It collects a large number of frontend-related technical resource sites, including Vue.js, React, Node.js, CSS3, HTML5, and JavaScript tutorial sites, popular JS frameworks, icon asset libraries, interaction design, development tools, and more, providing a convenient entry point to these resources.

This project is a personal blog template built to explore the possibility of rebuilding the Frontend8 website based on VitePress + CMS.

Github repository: <https://github.com/msyuan/vitePress-project>
